November 17, 2026 1:02PM EST
November 17, 2026 6:02PM UTC

MONITORING

November 9, 2026 6:34PM EST
November 9, 2026 11:34PM UTC

MONITORING

The File and Folder browsing and download functionality within the x360Recover Vault interface was temporarily taken offline.

We have completed the transition of the File and Folder Recovery experience to x360Recover Manager as part of our ongoing efforts to consolidate recovery workflows and other user experiences to x360Recover Manager.

As of x360Recover v17.8.1, File and Folder Mount and Browse capability is no longer available on Axcient Vaults. Partners can now use the Recovery Wizard in x360Recover Manager to browse and download files and folders. Learn more on using Recovery Wizard here:

https://docs.connectwise.com/x360Recover/Recover_with_x360Recover/File_and_Folder_Browsing_in_x360Recover_Manager

October 30, 2026 3:00PM EDT
October 30, 2026 7:00PM UTC

IDENTIFIED

The File Browser feature in x360Recover Vaults remains temporarily offline. ConnectWise engineers are aware of the issue with the x360Recover Vault File Browser and continue working to restore the service.

Please continue to use RMC / Recover manager to recover files:

docs.connectwise.com/x360Recover/Recover_with_x360Recover/File_and_Folder_Browsing_in_x360Recover_Manager

Additional information will be provided as it becomes available. We appreciate your patience as we continue to work towards a solution.
