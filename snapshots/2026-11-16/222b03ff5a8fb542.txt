Lead Source Report

3 min readUpdated October 28, 2026

Overview

The Lead Source Report helps you see which marketing channels are bringing in the most valuable leads. By tracking the number of leads and the revenue tied to them, you’ll get a clear picture of which sources are working best for your business.

This report focuses on the first revenue earned from a lead, making it easier to understand how much new work each source is generating. Whether you’re investing in referrals, your website, or social media, this report can help you make more informed decisions about where to focus your marketing efforts.

Permissions for the lead source report

To access the lead source report, users must be an admin user or have these user permissions:

View reports: ✅ Enabled

Show pricing: ✅ Enabled

Requests: View only (or a higher request permission level)

Quotes: View only (or a higher request permission level)

Jobs: View only (or a higher request permission level)

Invoices: View only (or a higher request permission level)

Set filters for the lead source report

The lead source report can be filtered by the date a lead was created in Jobber. To filter the lead source report, select the Date filter dropdown, then select a date range. Your options are:

Last week

Last 30 days

Last month

This year

Last 12 months

All time

Custom range

Columns for the lead source report

Columns in the lead source report can be customized by selecting the Columns button, then selecting the columns for the report from the columns list.

The options for columns that can be added to the lead source report are:

Lead source: This shows the name of the lead source if there are any leads from that source in the date range you selected.

Leads: Number of leads with a creation date in the selected date range.

Leads with request: Number of leads returned in the selected date range with a request associated (Note: This is not the number of requests associated with leads).

Leads with quote: Number of leads returned in the selected date range with a quote associated. (Note: This is not the number of quotes associated with leads)

Leads with job: Number of leads returned in the selected date range with a job associated. (Note: This is not the number of jobs associated with leads).

Leads with invoice: Number of leads returned in the selected date range with an invoice associated. (Note: This is not the number of invoices associated with leads).

Invoice value: The total amount from the first invoice linked to the lead. We only show the first one because that’s usually how people think about it: when a lead comes in from a lead source, it’s the first payment that counts, not any ongoing revenue.

Export the lead source report

To receive a spreadsheet version of the lead source report, click Export to CSV then select if you’d like to export the report with all columns or just the selected ones. The report will then be sent to the same email address that you use when you log into Jobber.

Exporting to CSV is a good option if you need to work with the data in the report, print the report, or share it with someone who is not a user in your Jobber account.
