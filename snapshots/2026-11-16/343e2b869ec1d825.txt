01/

What is Microsoft 365 and what features are included with a subscription?

Microsoft 365 is a subscription service that combines premium productivity apps, cloud storage, collaboration tools, security features, and AI-powered experiences in one solution. Depending on the plan you choose, Microsoft 365 can include apps such as Word, Excel, PowerPoint, Outlook, and OneNote; OneDrive cloud storage; real-time collaboration across devices; and Microsoft Copilot experiences in supported Microsoft 365 apps. Compare subscriptions here.

02/

Was Microsoft Office 365 renamed to Microsoft 365?

Microsoft rebranded many Office 365 consumer subscriptions as Microsoft 365 to reflect the evolution from traditional productivity apps to a subscription that also includes cloud services, security features, collaboration tools, and AI-powered experiences. Today, Microsoft 365 includes apps like Word, Excel, PowerPoint, Outlook, and OneNote, along with OneDrive cloud storage, real-time collaboration, and Microsoft Copilot AI experiences built into the apps you use every day.

03/

When do I need a Microsoft 365 subscription?

A Microsoft 365 subscription is a good choice if you want the full desktop versions of apps like Word, Excel, PowerPoint, Outlook, and OneNote, access to eligible Copilot experiences and AI-powered capabilities, and more cloud storage.

Free Microsoft apps are available for lighter, everyday use, but a Microsoft 365 subscription unlocks a broader set of productivity, storage, and AI-powered features.

04/

What is the difference between Microsoft 365 Basic, Personal, Family, Premium, and Pro?

Microsoft 365 offers several plans to fit different needs:
Microsoft 365 Basic includes 100 GB of cloud storage, security features, and select Microsoft 365 benefits. It does not include full desktop apps or advanced AI features.

Microsoft 365 Personal is designed for 1 person and includes premium Microsoft 365 apps, 1 TB (1000 GB) of cloud storage, and Copilot features.

Microsoft 365 Family includes the same core benefits as Personal, but with the ability to share benefits with up to 5 people. Plus, get 2 TB (2000 GB) of cloud storage shared across all users. Copilot AI features are available only to the subscription owner.

Microsoft 365 Premium includes everything in Family, plus advanced Copilot features and extensive AI usage limits.

Microsoft 365 Pro includes everything in Premium, plus the highest AI usage limits available for individuals and 5 TB (5000 GB) of cloud shared storage

The best plan depends on how many people will use it and how much access you want to advanced AI capabilities. Compare plans here.

05/

How is Copilot integrated across Microsoft 365 apps?

Microsoft Copilot is built directly into Word, Excel, PowerPoint, Outlook, OneNote, and Teams, so you can access AI assistance where you already work. It can help you draft documents, analyze data, create presentations, summarize emails and meetings, and chat with AI without switching between apps. By bringing AI into the Microsoft 365 apps you use every day, Copilot helps you work faster and stay focused on the task at hand.

06/

How does Microsoft use my data and protect my privacy?

Copilot is built on Microsoft's existing security, privacy, compliance, and Responsible AI commitments. Learn more here.

07/

What devices can I use Microsoft 365 on?

Microsoft 365 works across supported PCs, Macs, iPhones, iPads, Android phones and tablets, and web browsers, so you can access your apps and files from virtually anywhere. With a Microsoft 365 subscription, each person can be signed in on up to five devices at the same time, making it easy to stay productive across all your devices.

08/

Why should I choose Microsoft 365 over tools like Google Workspace?

Microsoft 365 combines full desktop apps, cloud services, and AI in one subscription. You can use Word, Excel, PowerPoint, Outlook, and OneNote across PC, Mac, mobile devices, and the web, with the ability to work both online and offline. It also includes Microsoft Copilot, an AI assistant built directly into your apps to help draft documents, analyze data, create presentations, summarize information, and more without leaving your workflow. For many users, Microsoft 365 offers the convenience of familiar desktop apps, seamless collaboration, and AI-powered assistance all in one place.
